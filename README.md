# hafizulabdullah.com

Personal academic website of Dr. Mohd Hafizul Afifi Abdullah, live at [hafizulabdullah.com](https://hafizulabdullah.com).

Built with [Jekyll](https://jekyllrb.com/) on the [al-folio](https://github.com/alshedivat/al-folio) theme and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `master`.

## Run locally

```bash
bundle config set --local path vendor/bundle
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

Theme documentation: [INSTALL.md](INSTALL.md), [CUSTOMIZE.md](CUSTOMIZE.md), [FAQ.md](FAQ.md).
